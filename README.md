# Photo Report Bot — бот создания фото-отчётов Word

Telegram-бот, который собирает документ `.docx` по шаблону: выбор типа
шаблона → метаданные → номера контейнеров → пошаговая вставка
фото с подтверждением → готовый файл.

## Структура отчёта

* **Вводный блок** — фиксированные подписи, меняются только фото (24 фото).
* **На каждый контейнер** — 8 фото в едином порядке.
* Таблица 2 колонки: строка с фото, ниже — строка с подписью.

Всё это задано в `config.py` — там же добавляются новые типы шаблонов.

### Доступные шаблоны

* **Flexitank / Sunflower oil** — 8 фото на контейнер.
* **Flexitank / Sunflower oil — версия 2** — 10 фото на контейнер
  (добавлены Valve seals и Factory valve seal).

Бот показывает список шаблонов кнопками при /start — новые шаблоны
из `TEMPLATES` появляются автоматически.

### Удобства при съёмке

* **Загрузка пачкой** — можно отправить несколько фото альбомом,
  они заполняют ячейки по порядку (одно подтверждение на пачку).
* **Кнопка «⬅️ Назад»** — вернуться на предыдущую ячейку и переснять её.
* **Автоочистка** — после генерации отчёта все временные фото
  пользователя удаляются автоматически.

## Установка

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Токен

Получите токен у [@BotFather](https://t.me/BotFather) и укажите его любым способом:

```bash
export BOT_TOKEN="123456:AA..."      # Linux/macOS
set BOT_TOKEN=123456:AA...           # Windows
```

Не записывайте токен в исходный код. На Amvera используйте секретную переменную `BOT_TOKEN`.

## Запуск

```bash
python app.py
```

Затем в Telegram откройте своего бота и нажмите **/start**.
Команда **/cancel** — сбросить текущий отчёт.

## Сохранение состояния при перезапуске (Redis)

По умолчанию используется память (`USE_REDIS=0`): состояние диалога теряется при перезапуске. Для сохранения состояния включите `USE_REDIS=1`, настройте доступный Redis и постоянные каталоги `WORK_DIR` / `OUT_DIR`.

### 1. Установите и запустите Redis

```bash
# Ubuntu/Debian
sudo apt install redis-server
sudo systemctl enable --now redis-server

# macOS (Homebrew)
brew install redis
brew services start redis

# или через Docker
docker run -d --name redis -p 6379:6379 redis:7
```

Проверка: `redis-cli ping` → должно вернуть `PONG`.

### 2. Настройки (переменные окружения)

| Переменная | По умолчанию | Описание |
|-----------|--------------|----------|
| `USE_REDIS` | `0` | `1` — Redis, `0` — хранение в памяти |
| `REDIS_URL` | `redis://localhost:6379/0` | адрес Redis |

Пример с паролем / удалённым хостом:

```bash
export REDIS_URL="redis://:пароль@10.0.0.5:6379/0"
```

Если пакет Redis отсутствует или URL некорректен, используется память.
Ошибка подключения к настроенному серверу Redis не вызывает автоматический переход на память; убедитесь, что сервер доступен.
Чтобы сознательно отключить Redis: `export USE_REDIS=0`.

## Как добавить новый шаблон

В `config.py` в словаре `TEMPLATES` добавьте новый ключ с полями:
`title`, `intro` (список `(подпись, кол-во)`), `per_container`
(список подписей), `meta` (дефолтные метаданные). См. закомментированный
пример `template2` в файле.

## Примечания

* Фото пользователей хранятся временно в папке `work/<user_id>/`,
  готовые документы — в `out/`.
* Бот многопользовательский: у каждого своё состояние и своя папка.
  Состояние переживает перезапуск только при настроенном Redis (см. выше).

## Запуск на Amvera и диагностика

Точка входа контейнера — `python app.py`, HTTP — `0.0.0.0:3000`.
`BOT_TOKEN` обязателен для работы Telegram; без него доступна только диагностика.
`/health` — жив ли процесс, `/ready` — подтверждён ли успешный запрос polling Telegram (503 до подключения).
При ошибке запуска `/health` остаётся доступен, `/ready` возвращает 503.
При активном webhook polling не запускается: сначала явно удалите webhook в Telegram.
Не запускайте два экземпляра polling с одним токеном, в том числе в превью и на платформе одновременно.

Проверки: `python -m unittest discover -s tests -v` и `python -m pip check`.
Документы и черновики генерируются только в Word (.docx). PDF-конвертация отключена, LibreOffice не требуется.
Ошибка платформы `Downloading archive from S3 ... 404` возникает до запуска приложения и требует проверки артефакта/повторного развёртывания на Amvera.
